# D-04 — Build the OpenXR API layer in v1 or defer

**Status:** ANSWERED by the human, 2026-08-11 (kit default adopted, recorded
as examined — not an unexamined default).

**Decision:** Defer. v1 ships T2 (non-XR mirror capture) and T3 (desktop
harness) only; A3 is the v1 actuation floor. The API layer plane (`layer/`)
stays scaffold-only; W6 remains gated. Starting W6 requires a fresh explicit
human decision, per the kit's human stop points.

**Consequences:**
- v1 capture fidelity is capped at T2/T3; every run artifact and report must
  carry its tier honestly (tier-honesty gate).
- F-010 (exact composited-frame capture) is never fully resolved in v1. This
  deferral and its cost must be disclosed plainly in README and SHIP.md —
  users are told what T2 proves and what it does not.
- The layer worker (oxr-w-layer) stays idle; `layer/` keeps the
  explicit-layer CI gate green with no implicit-layer code paths.
- W0-02 (no C++17 compiler on host) stays an open P0 against any future W6.
