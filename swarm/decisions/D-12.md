# D-12 — Inference locality

**Status:** ANSWERED by the human, 2026-08-09 (chose option B). Supersedes
kit v2.1's D-11 (same topic, same answer); supersedes this repo's earlier
"local-only hard requirement" default.

**Decision:** Local first, not local only. Local backends are the default
and require no network permission. Hosted backends are available, permitted
providers only (vendor gate unchanged: no Meta, OpenAI, xAI), and off until
a human edits configuration. A hosted adapter opens egress to exactly one
allowlisted provider domain and nothing else.

**The trade-off, carried verbatim from kit v2.1 §3.6:** "Every hosted
adapter you enable is a path by which a screenshot of your project and its
scene tree leave the machine. That is the point of the feature and it is
not a defect, but it means the egress allowlist is the control that decides
how far a successful prompt injection travels."

**Consequences:**
- The permanent denylist (api.openai.com and every other excluded-vendor
  endpoint) is applied after allowlist resolution, is not configuration,
  and fails closed. (D-11)
- README and the kit no longer claim "no hosted component of any kind";
  they say "no hosted component required; hosted model providers are
  opt-in, single-domain, never an excluded vendor."
