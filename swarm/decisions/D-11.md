# D-11 — Vendor gate scope: artifacts vs wire format

**Status:** ANSWERED (human delegated to agent, 2026-08-09)
**Decision:** The gate covers artifacts, not interface shapes. The
OpenAI-compatible JSON message format spoken over plain `httpx` involves no
OpenAI code, service, or model, and is permitted. The `openai` pip package,
any vendor SDK, and any vendor-hosted endpoint remain banned (F-019 stands).

**Rationale:** the OpenAI-compatible shape is a de facto standard spoken by
llama.cpp, vLLM, LocalAI, and LM Studio. Banning the shape would exclude
every major local server for zero security gain; banning the artifacts
removes the actual supply-chain surface.
