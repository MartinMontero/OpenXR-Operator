# D-17 — Contract amendment: delimit untrusted observation content (P1-04)

**Status:** RULED by the orchestrator, 2026-10-28 — APPROVED and implemented.
Not a human decision; no human stop was triggered (no security gate weakened,
no Rule 9 action, no unlisted model, no unexamined default). Request and
rationale: `swarm/requests/contract-amendment-P1-04-observation-delimiting.md`.

**Amendment:** `render_user_text()` in the frozen contract `model.py` now
encloses the scene tree in `<scene_tree>` tags with an explicit
UNTRUSTED-data warning, and serializes with compact separators. Signature
unchanged; behavior of the rendered string changed.

**Consequences:**
- All current and future adapters (both shipped local adapters; D-15's hosted
  Kimi and other future hosted adapters) inherit injection delimiting.
- Test TC-SEC-009 (delimiters + warning present; hostile node name verbatim
  inside the tags) is part of the operator suite.
- This is spotlighting: it reduces, does not eliminate, prompt injection. The
  schema gate, capability allowlist, and approval gate remain the load-bearing
  controls and may not be weakened on the strength of this amendment.
