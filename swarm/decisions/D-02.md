# D-02 — Accept Meta funding proximity in the Godot XR toolchain

**Status:** ANSWERED by the human, 2026-08-11 (kit default adopted, recorded
as examined — not an unexamined default).

**Decision:** Accept, documented. The Meta–W4 Games / Khronos–Godot OpenXR
funding proximity (kit B-14) is funding/governance proximity, not a technical
dependency: no Meta code, artifact, model, or API enters the dependency tree.
The vendor gate (`tools/vendorscan.py`) continues to enforce the artifact
tier in CI; this decision covers only the proximity tier.

**Consequences:**
- W1 unblocked.
- The funding-proximity facts and this rationale are documented in README so
  the acceptance is visible, not implicit.
- Any future change from proximity to technical dependency (a Meta-authored
  artifact entering the tree) is a vendor-gate Blocker, not a D-02 matter.
